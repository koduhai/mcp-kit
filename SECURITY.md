# Security Policy

`@koduhai/mcp-kit` deals with authentication and token verification, so we take
security reports seriously and appreciate responsible disclosure.

## Supported versions

This project is pre-1.0. Security fixes land on the latest released `0.x` minor.
Once 1.0 ships, this policy will list the supported version range.

| Version      | Supported |
| ------------ | --------- |
| latest `0.x` | ✅        |
| older        | ❌        |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Instead, use one of the following private channels:

- **Preferred:** GitHub's private [security advisory](https://github.com/koduhai/mcp-kit/security/advisories/new)
  ("Report a vulnerability" on the repo's Security tab).
- **Email:** [security@koduhai.com](mailto:security@koduhai.com)

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce (a minimal proof of concept is ideal).
- Affected version(s) and environment.
- Any suggested remediation, if you have one.

## What to expect

- **Acknowledgement** within 3 business days.
- An assessment and, if confirmed, a fix timeline. We aim to release a patch for
  confirmed high-severity issues within 30 days.
- Credit in the release notes / advisory, unless you prefer to remain anonymous.

Thank you for helping keep the MCP ecosystem secure.
